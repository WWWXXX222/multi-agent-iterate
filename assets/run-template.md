# 运行契约与检查点

仅填写本任务需要的字段；此文件放在业务运行目录，不放回 skill 包。

## 目标与边界

- 用户请求：
- 最终交付物与位置：
- 基线文件/版本：
- 原始来源与已确认决定：
- 可改范围 / 必须保留 / 不在范围：
- 已有授权（包括发布等动作是否在范围）：

- 必须精确完成的轮数（如用户指定）：
- 停止条件：
- 实际可用并发 / 工具 / 模型：
- 独立性限制：
